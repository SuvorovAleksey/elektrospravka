# ⚡ ЭлектроСправка — База знаний и экзаменационные вопросы по электробезопасности

Веб-приложение и PWA для подготовки и проверки знаний по электробезопасности (I–V группы допуска, включая ЭТЛ и электроустановки выше 1000 В).

## Возможности:
- 594 актуальных вопроса с ответами и ссылками на НПА (ПТЭЭП № 811, ПОТЭЭ № 903н, Приказ № 1070, Приказ № 757, Приказ Минздрава № 220н и ПУЭ 7);
- 100% автономная работа офлайн (PWA / Service Worker);
- Умный поиск с приоритетным ранжированием по вопросам и ответам;
- Адаптивный дизайн Material 3 (светлая и тёмная темы);
- Оптимизировано для iOS (Safari WebClip) и Android (Chrome).
